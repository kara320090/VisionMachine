# DB 마이그레이션 위치

SQL 원본은 설치 패키지에도 포함되도록 `server/src/vm_server/migrations/`에 있다. 두 곳에 SQL 복사본을 만들지 않는다.

저장소 루트에서 `python -m vm_server init-db`를 실행하면 `storage/visionmachine.db`와 업로드용 폴더를 준비한다. 기존 v1 DB에 다시 실행해도 데이터를 지우지 않는다. 알 수 없는 버전이나 버전 정보가 없는 기존 테이블은 자동 변경하지 않고 실패한다.

현재 HTTP 서버는 메타데이터 검증만 한다. 이 명령이 성공해도 사진 업로드·DB 저장·조회 API가 구현된 것은 아니다. 다음 마이그레이션은 기존 SQL을 고쳐 배포하지 말고 새 버전과 실제 업그레이드 시험으로 추가한다.
