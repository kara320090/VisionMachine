# AI 첫 구현: 실제 RGB 기준선

담당: 한윤섭·최승빈. ml/README.md, model card 양식, 공통 계약·데이터 manifest를 읽는다.
- 실제 이용조건 확인 자료와 고정 분할이 있는지 먼저 확인한다. synthetic fixture로 진단 성능을 학습·주장하지 않는다.
- OpenCV 전처리/품질 기준과 사전학습 CNN의 학습·추론 코드, 설정·seed·분할 버전·모델 카드 틀을 만든다. 실제 자료가 없으면 loader/코드 검증까지 진행하고 학습 미실행을 명시한다.
- 학습과 추론이 같은 전처리를 쓰게 한다. 모델 가중치·실험 상세는 artifacts, 코드·설정·해시·검증 가능한 집계만 Git.
- Predictor 인터페이스와 결과 계약을 구현하되 가중치가 없으면 pending_model을 유지한다. 랜덤 클래스를 real_model로 반환하지 않는다.
- 이후 센서 단독·융합은 실제 짝자료에서만 만들며 같은 train/val/test 분할을 사용한다. 개선 비교·임곗값 결정은 val로 하고 최종 test는 버전 고정 후 독립평가에만 사용한다. 스케일러/결측처리는 train에서만 학습한다.
- 오류·작물/조명별 편차·오경보·미탐·보류율을 분석한다. 실제 최종시험을 보고 모델을 튜닝하지 않는다.

산출물: RGB 재현 코드·설정·실행방법·모델 인터페이스 시험. 실제 학습 가능 시에만 실제 모델 카드와 결과를 추가한다.
