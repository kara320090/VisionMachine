# 데이터 첫 구현: 실제 수집 기준과 검사

담당: 한윤섭·유재윤. data/README.md, data-pipeline/README.md, docs/DATA_PROTOCOL.md를 읽는다.
- data/catalog/sources.csv의 후보를 공식 상세 페이지에서 확인하고 실제 확보/미확보·이용조건·대상 작물·라벨·센서 대응을 기록한다. 접속 권한이 없으면 미확인으로 남긴다. 다운로드 완료를 꾸미지 않는다.
- 원본 보존, ID 부여, 파일 디코딩·실제 해시 검사, 중복·결측·사진 품질 검사 코드를 작성한다. 공개/자체 라벨 매핑과 근거를 구분한다.
- 수집 표·라벨 표·교정 표를 실제 자원에 맞게 구체화한다. 인원별 작물·표본 수·재배 공간은 확인 없이 배정하지 않는다. 전원이 교대 수집하고 이 파트는 기준·품질·평가 코드를 담당한다.
- 현재 그룹 누수 검사를 실제 split 생성 코드와 연결한다. 같은 개체·과실·원식물·구매묶음·중복은 같은 분할, 임의 이미지 단위 random split 금지. 충분한 그룹이 없으면 분할 불가능 사유를 보고한다.
- 시험용 그룹은 수집 초기부터 준비한다. 최종시험 정답은 공개 Git에서 제외하고 예측 고정 후 대조하는 절차를 만든다.
- 3주차까지 확정할 검증범위/정답 근거/판단 불충분 항목을 별도 표로 정리한다. 임의 학습 정확도나 수집 완료 수를 만들지 않는다.

산출물: 자료 조사표, 검사 코드와 실패 사례, 수집/라벨 기준, split 절차·버전. 실제 다운로드 원본은 Git에 넣지 않는다.
