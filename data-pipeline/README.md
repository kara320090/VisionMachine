# 데이터·실험·독립평가 — 한윤섭·유재윤

현재 validate_manifest.py는 CSV 명세·ID·상대경로·해시 형식·개체/부모식물/구매묶음/중복 그룹의 split 누수를 검사한다. 같은 해시, 같은 개체 또는 묶음으로 연결된 자료는 하나의 분할에 있어야 한다. 사진 존재·실제 해시·근접 중복 탐지·라벨 타당성·이용조건 진위는 아직 검사하지 않는다.

다음 파일:
```text
src/vm_data/
  sources/             공식 자료별 다운로드/목록 생성(허가된 자료만)
  ingest.py            원본 보존·ID 부여·해시 확인
  quality.py           디코딩·중복·결측·촬영 품질
  labels.py            원본/학습 라벨 매핑·교차검수
  split.py             연결 그룹 단위 분할, seed/버전/그룹 수 기록
  export.py            공통 학습 입력 manifest 생성
  evaluate.py          예측-정답 결합·작물별 지표·보류율
```

분할은 이미지 수만 보고 임의 80/10/10으로 고정하지 않는다. 실제 독립 개체/묶음 수를 보고 팀이 정한다. 가능한 수가 부족하면 파일을 억지로 쪼개지 말고 검증범위의 한계를 기록한다. 같은 과실의 여러 장, 잘라낸 이미지, 증강 이미지는 원본과 같은 그룹에 둔다.

라벨은 관찰 상태와 원인 후보를 분리한다. 물 제한 처리나 입력 센서값 자체만으로 원인 정답을 만들지 않는다. 모르는 상태는 uncertain/unlabeled로 두고 최종 평가 대상 선정 기준을 사전에 정한다.

독립시험 라벨은 비공개 저장공간에서 관리한다. 12주차 모델/코드/분할/임곗값을 고정하고 13주차 예측 파일 해시·시각을 먼저 기록한 다음 정답과 대조한다. AI 겸임자의 최종시험 라벨 접근은 절차로 관리한다.
