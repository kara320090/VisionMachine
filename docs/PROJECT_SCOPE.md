# 합의된 범위와 아직 결정하지 않은 사항

## 고정 범위
휴대폰 정지사진 → 같은 대상의 USB 실측 → 휴대폰 Wi-Fi/모바일데이터 → 서버 저장·AI → 결과·근거·이력. 서버와 AI를 휴대폰 안에서 전부 실행하는 구조로 바꾸지 않는다.

기본 센서: UNO R4 Minima 1대 + DFR0265 + SEN0308 + SEN0334, 무납땜 완성 모듈과 케이블. 추가 센서: SEN0364, SEN0206를 DFR0759로 같은 보드에 연결하는 구성. 전압·주소·단자 규격상 연결 가능하며 실물/휴대폰 통합시험 완료는 아니다. 배선 근거는 docs/HARDWARE.md를 따른다. LN-3·당도계·전자저울을 기본 구매나 구현 필수조건으로 추가하지 않는다. 광학 값은 내부 영상이 아니다.

후보: 방울토마토, 고추, 깻잎, 상추, 청경채, 케일, 바질, 로즈마리. crop code는 계약 문서를 따른다. 공개자료 후보는 AI-Hub 식물 병 유발 통합/원예식물 물주기 생육/토마토 통합 데이터, HydroGrowNet, PlantVillage다. 다운로드·이용조건·표본·센서 대응을 검토한 뒤 채택하며 확보 완료로 쓰지 않는다.

출력은 뚜렷한 이상 미관찰 / 이상 의심 / 판단 불충분과 근거·추가 확인사항. `pending_model`은 분석 상태이지 정상 판정이 아니다. 병명 확정·섭취 안전·검증되지 않은 Brix/내부결함을 보장하지 않는다.

실제 자체 짝자료와 동일 시험 집합으로 RGB 단독·센서 단독·융합을 비교한다. 융합이 더 나쁘거나 판단을 보류하는 결과도 기록한다.

## 2026-09-19 예산 갱신
사용자가 확정한 학교 지원액은 500,000원이고 Google Play 등록비 원화 예산은 35,000원, Codex 사용 예산은 1개 159,000원이다. 2026-09-19 판매 페이지 표시가와 일반 내륙 배송료를 다시 계산했다. 센서·Arduino·등록·Codex 등 휴대형 기구 제외 공통액은 357,580원이고, 드라이버·드릴·납땜 없이 조립하는 U-Grip·파우치·센서판 구성 상한은 64,440원이다. 바질·로즈마리 2개와 화분·흙까지 포함한 총액은 454,250원, 깻잎까지 더한 3개안은 식물 배송을 두 번 계산해도 최대 482,100원이다. 세부 산식과 링크는 [PURCHASE_PLAN](PURCHASE_PLAN.md)에 있다.

가격·재고·묶음배송은 결제 시 변할 수 있으며 실제 지출은 카드 승인액과 영수증으로 기록한다. 남는 지원금을 맞추기 위한 품목을 만들지 않는다. 전자저울과 근거 없는 유료 서버/저장소는 제외했으며, 서버의 저장·추론 기능은 로컬 개발부터 유지한다. 이 저장소에 서명·개인정보가 담긴 행정 원본은 넣지 않는다.

현재 실제 구매 예상액과 과거 조건부 제출안 491,890원은 산정 범위가 다르다. 491,890원에 Codex 159,000원을 더한 650,890원을 현 계획으로 사용하지 않는다. 실제 구매안에 포함하지 않은 품목과 견적 전 상한을 되살려 지원금 500,000원에 맞추지 않는다.

## 기술 선택안과 확인 필요
Python 3.12/FastAPI, Android Kotlin/Compose, Python ML, Arduino C++를 시작안으로 선택했다. 팀이 언어·라이브러리를 이미 정했다면 기존 합의에 맞춰 최소 변경한다. SQLite는 로컬 시작안이며 운영 DB·호스팅·사용자 인증 방식·SDK/Gradle 버전은 후속 결정이다. 클라우드 무료 제공·GPU·모종/배양토 확보를 가정하지 않는다.

표본 수·대상 상태·라벨 정답 근거·교정계수·정확도·실제 학기 시작일·계정 소유자·출시일은 미확정이다. 3주차까지 여건에 맞는 1차 검증범위를 결정한다. 기준 휴대폰 호환성과 원시/보정 단위도 실제 확인한다.
