## 결제 순서와 중단 조건

1. 휴대폰 케이스 포함 폭이 50.8~88.9 mm인지 확인한다. 벗어나면 U-Rig Pro를 결제하지 않는다.
2. 납기가 긴 디바이스마트·아이씨뱅큐 부품을 먼저 주문한다. DFR0265·DFR0759는 주문품/반품 제한을 확인한다.
3. 전자부품을 받으면 DFR0759 입력 케이블 1개와 I2C 센서용 케이블 3개, SEN0308 일체형 케이블을 대조한다.
4. EVA 케이스를 받은 뒤 내부가 166×84×45 mm 이상인지 잰다. 작으면 접착하지 않고 교환한다.
5. 작물 키트는 기본모종 `대저(짭짤이)토마토`, 추가모종 `스위트바질`로 선택하고 상품 16,500원과 배송비 3,000원을 결제 화면에서 확인한다. 배양토 포함 여부가 확인되지 않으면 판매자에게 문의하고, 포함되지 않으면 학교 승인 없이 품목을 임의 추가하지 않는다.
6. 결제 화면의 옵션·상품가·배송비 합계가 표와 다르면 결제를 멈추고 총액을 다시 계산한다. 500,000원을 넘는 경우 임의 품목을 추가·삭제하지 말고 변경 근거를 기록한다.
