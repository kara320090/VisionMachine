# 순서와 완료 조건

수업 주차 기준이며 달력 시작일을 새로 만들지 않는다. 이미 지난 항목은 최초 점검에서 확인한다.

| 주 | 완료 목표 | 주관·인계 |
|---|---|---|
| 1 | 촬영·사진 저장 APK, API/USB 형식, 자원 확인 | 앱·서버·계측 각 구현, 데이터 자료표 |
| 2 | 실제 사진 업로드, 공개 이미지–라벨 100쌍 검사 목표, 기초 USB 호환시험 | 앱↔서버, 데이터↔AI, 계측↔앱 |
| 3 | 실제 USB 수신·사진 연결 저장, 검증범위/라벨/분할 기준 | 계측↔앱, 데이터 주관 |
| 4 | 첫 실제 RGB 모델 서버 추론과 앱 결과 | AI↔서버↔앱, 공동 본 수집 |
| 5 | 사진→실측→서버 AI→결과 기본 앱 | 앱·서버, 관련 파트 시험 |
| 6 | 센서 단독·첫 융합·동일 자료 비교, 광학 진행 판단 | AI·데이터·계측 |
| 7 | 베타·시험 배포·오류표 | 앱 주관, 각 파트 수정 |
| 8 | 중간고사, 당번 수집·백업·앱 시험 | 데이터/당번, 서버, 앱 |
| 9 | 수업 6개 비전 에이전트 과제, 데이터 정제 | 수업 전원, 데이터 주관 |
| 10 | 세 모델 개선·비교, 실제 모델 반영 | AI↔데이터/계측, 서버↔앱 |
| 11 | 다른 기기·배경, 반복성·복구, 담당 보고서 | 앱/계측/서버/데이터 |
| 12 | 기능·라벨·분할·모델·임곗값·평가코드·앱·서버 고정 | 각 파트 고정, 서버 취합 |
| 13 | 미사용 개체/과실 독립시험·처음 사용자 시험 | 데이터 평가, 앱 사용성 |
| 14 | 결과·한계·리허설·정산, ViT 수업 실습 별도 | 각 파트·팀장 |
| 15 | 실제 앱·센서·서버·AI 시연, 코드/명세/모델/평가 제출 | 각 파트 시연·전원 발표 |

5주차 기본 앱은 최종 정확도 검증 완료가 아니다. 장치 배송이 늦으면 명시된 모의 패킷으로 연결 개발을 계속한다. 모델이 늦으면 분석 대기와 mock을 구분한다. 모델/기능을 최종시험 결과에 맞춰 고친 경우 최초 독립평가 결과와 분리한다.
