# 설계 근거와 적용 범위

사용자 제공 학교 양식·전체 프롬프트·팀 공지/15주표·2026-09-10 승인 예산표를 바탕으로 대화에서 확정한 내용을 적용했다. 원본 개인정보·서명·학교 문서는 이 공개 저장소 패키지에 복사하지 않았다. 실명 공동담당은 사용자 제공 배정이며 GitHub 계정 매핑은 미확정이다. 2026-09-27 사용자 결정인 기업연계형 신청, 지원금 500,000원, 큰토마토·바질 모종·화분 키트 19,500원, 참여기업 검토회의 70,090원 편성을 최신 기준으로 반영했다. 생성AI 등 토큰 사용 가능 여부는 학교 답변 전이므로 159,000원을 개발·시험용 SW·온라인 서비스 포괄 비목으로만 기록했다. 기업정보와 협약 체결 사실은 제공되지 않았다.
