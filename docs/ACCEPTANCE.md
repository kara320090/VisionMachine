# 기능별 완료 판정

| 분야 | 확인해야 할 동작 |
|---|---|
| 계약 | 예제와 실제 수신값이 같은 버전·단위를 사용, 결측/타임존/교정/모의 표시 검증 |
| 앱 촬영 | 기존 카메라 앱 호출, 원본 크기 URI 저장, 취소·프로세스 복귀 후 잘못된 사진 연결 없음 |
| USB | 기준 실기기 인식·권한·전원·실측·부분 패킷·분리·재연결, 오래된 요청 응답 재사용 방지 |
| 업로드 | 실제 JPEG/PNG를 검증하여 저장, 검사 ID 재시도 중복 없음, 내용 변경 충돌, 실패 후 임시파일 정리 |
| 서버 | 재시작 후 조회·권한별 접근·오류·삭제·백업/복구·로그 비밀 제외 |
| AI | 실제 학습모델·전처리·분할 버전·비교 결과 재현, 모델 없음/미지원/결측 시 판단 보류 |
| 데이터 | 실제 이용조건·원본 보존·라벨 근거·중복/결측·개체/과실/묶음 누수 검사 |
| 독립시험 | 시험자료 접근 통제, 예측 먼저 저장·그 후 정답 대조, 재튜닝 결과와 구분 |
| 배포 | APK 설치·실기기 시험·서명키 관리·계정/테스터/스토어 정책 확인 |

실험 반복 횟수·성능 목표·모델 선택은 근거 확인 후 결정한다. mock으로 통과한 테스트와 실제 장치/모델 시험을 구분해서 기록한다.
