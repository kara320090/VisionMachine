# 휴대형 시제품 치수 검토

검토일: 2026-09-20. 판매 페이지가 공개한 **외형 치수**와 제조사 보드 치수를 대조했다. EVA 하드 케이스 내부 치수, 실제 스마트폰 케이스 폭, 볼헤드 높이는 공개되지 않았으므로 실물 확인 전에는 확정값으로 쓰지 않는다.

![휴대형 부품 치수 대조](assets/hardware-fit-check.png)

## 결론

기존 `U-Grip Pro + 중형 파우치` 그림은 그대로 구매·조립하면 안 된다.

- U-Grip Pro 외형 폭은 190 mm인데 중형 파우치 외형 폭은 211 mm여서 파우치가 21 mm 더 넓다.
- U-Grip Pro 기본 구성에는 스마트폰 홀더가 없다. 별도 홀더를 사야 하므로 기존 구매표의 “휴대폰 클램프 포함” 설명이 틀렸다.
- 길이 175 mm인 SEN0308을 U-Grip 손잡이에 세로로 보관하는 방법은 손잡이의 실제 직선 유효 길이가 공개되지 않아 확인할 수 없다.

따라서 스마트폰 클램프가 내장된 **Ulanzi U-Rig Pro**와 외형 230×150×70 mm인 **EVA 하드 케이스**를 사용한다. 케이스는 중앙 틀 안이 아니라 아래 가로대의 뒤/아래에 가로로 묶는다. 내부 치수를 확인하기 전에는 접착재를 붙이지 않는다. SEN0308은 손잡이가 아니라 케이스 바깥 전면에 가로로 묶는다.

|---|---:|---|---|
| U-Grip Pro | 190 × 200 × 78 mm | 과거 중형 파우치 211 mm가 그립 폭보다 21 mm 큼 | 기존안 제외 |
| U-Rig Pro | 외형 250.8 × 44.5 × 130.2 mm, 내부 틀 215.9 × 44.5 × 123.8 mm | 케이스 폭 230 mm는 그립 외형보다 20.8 mm 작지만 내부 틀보다 14.1 mm 큼. 높이 150 mm도 내부 틀보다 26.2 mm 큼 | 틀 안 수납 불가, 아래/뒤 장착 |
| U-Rig Pro 휴대폰 클램프 | 50.8~88.9 mm | 휴대폰 케이스 포함 폭이 88.9 mm 이하여야 함 | 주문 전 휴대폰 실측 |

| SEN0364 | 22 × 20 mm |  |  |

제어부의 `165.58 × 83.34 × 45 mm`는 제품 치수가 아니라 **사용할 최소 내부 공간 기준**이다. 원시 보드 배치 `115.58 × 53.34 mm`에 케이블 굽힘과 절연 간격을 더했다. 케이스 외형과 이 값을 비교해 수납을 확정하지 않는다. 제품을 받은 즉시 자로 내부의 가로·세로·깊이를 재서 세 값이 모두 기준 이상일 때만 듀얼락을 붙이고 사용한다.

케이스를 U-Rig Pro 아래에 겹침 없이 달았을 때 본체의 보수적 외형은 약 **250.8 mm(폭) × 70 mm(깊이) × 280.2 mm(높이)**다. 높이는 `U-Rig 130.2 + 케이스 150`으로 계산했다. 실제로 가로대와 케이스가 겹치면 더 낮아진다. PT-3 길이 105 mm는 본체 폭 안에 들어오지만, 현재 볼헤드 판매 페이지가 높이를 제공하지 않아 측정 헤드까지 포함한 완성 높이는 실물 전에는 확정할 수 없다.

## 조립 전 통과 조건

1. 휴대폰 케이스 포함 폭이 50.8~88.9 mm이고, 클램프에 끼웠을 때 카메라와 USB-C 포트가 가려지지 않는다.
2. 케이스 내부 실측이 166 × 84 × 45 mm 이상이다.
3. 케이스를 빈 상태로 U-Rig Pro 아래 가로대에 타이 두 개로 묶었을 때 양쪽 손잡이와 스마트폰 조작을 막지 않는다.
4. UNO 적층 보드와 허브를 넣은 뒤 지퍼가 PCB·커넥터·케이블을 누르지 않는다.
5. PT-3에 센서 두 개를 붙인 뒤 감지창, 커넥터, 콜드슈 체결부가 모두 노출된다.
6. SEN0308을 케이스 바깥에 가로로 고정했을 때 금속 끝이 손잡이 밖으로 돌출되지 않는다.
7. 모든 부품을 단 상태에서 30초간 양손으로 들고 천천히 기울여도 케이스·센서판·프로브가 움직이지 않는다.

1~6 중 하나라도 실패하면 케이블을 억지로 꺾거나 지퍼를 눌러 닫지 않는다. 내부 기준을 만족하는 더 큰 케이스로 교환하거나 제어부를 별도 휴대하고, 휴대폰이 맞지 않으면 U-Rig Pro 구매를 중단한다.
