2026-09-19 사용자 결정: 모든 파트가 `main`에서 작업하고 검증한 단위마다 즉시 commit·push한다. 기존의 파트별 기능 브랜치 안내를 대체한다. 다른 사람이 먼저 올렸다면 내 커밋과 상대방 커밋을 병합하여 둘 다 보존한다. 상세 절차와 충돌 처리 기준은 [GIT_COMMITS](GIT_COMMITS.md)를 따른다.

2026-09-20 치수 검토: U-Grip Pro는 스마트폰 홀더가 별도이며 190 mm 외형 폭보다 중형 파우치 211 mm가 넓어 제외했다. 내장 클램프와 내·외형 치수가 공개된 U-Rig Pro로 교체했다. 파우치 내부 치수와 실제 스트랩 위치는 공개 정보만으로 확정할 수 없어 [HARDWARE_FIT_CHECK](HARDWARE_FIT_CHECK.md)의 실물 통과 조건을 구매·조립 게이트로 둔다.

2026-09-20 구매안 갱신: 개체 단위 분리·독립시험을 위해 자체 재배 대상을 대추방울토마토(빨강) 2개체와 바질 2개체로 확대했다. 두 모종은 같은 옥션 판매자의 묶음배송 1회를 적용한다. 왜성 토마토로 확인되지 않아 토마토에는 약 25 L 부직포 화분과 지지대, 바질에는 18×25 cm 화분을 배정하고 상토·배양토 총 60 L를 잡았다. 최신 표시가를 반영한 총 계획액은 492,190원이며, 내부 치수가 공개되지 않은 파우치는 예산에 포함하되 확인 전 결제를 보류한다.

새 선택은 이유·대안·영향 파트·검증 결과를 날짜와 함께 기록한다. 현재 선택안을 이미 운영 중인 환경처럼 설명하지 않는다.
