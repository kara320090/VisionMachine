# 담당과 인계

| 파트 | 실제 공동 담당 | 주 작업 위치 |
|---|---|---|
| ① 서버·모듈 통합 | 정회서·이봉헌 | server/, scripts/, 배포·운영 문서 |
| ② AI 구축 | 한윤섭·최승빈 | ml/, 모델 입출력 계약 |
| ③ 데이터 수집·실험 설계·독립평가 | 한윤섭·유재윤 | data-pipeline/, data/catalog·templates, 평가 절차 |
| ④ Android 앱 | 이봉헌·유재윤 | apps/android/ |
| ⑤ 하드웨어·계측 | 최승빈·정회서 | firmware/, 보정·반복성·광학 기록 |

이봉헌은 서버·앱 개발에 일정·구매계획/집행내역 관리·교수 소통·통합 조정을 더한다. 한 사람의 두 파트는 모두 실제 개발 분야다. GitHub 사용자명은 아직 확인되지 않았으므로 CODEOWNERS에 임의 계정을 넣지 않는다.

공통 계약은 관련 두 파트가 검토한다. 앱↔서버: 업로드/결과/오류. 앱↔계측: USB 요청/응답. 데이터↔AI: 라벨/분할/결측/이용조건. 계측↔AI: 교정/특징/단위. AI↔서버: 모델/전처리/버전/실행법.

사진·실측·재배 관리는 전원이 교대로 분담한다. 데이터 파트가 혼자 모든 촬영을 하지 않는다. 독립평가 운영은 데이터 파트가 주관한다. AI 겸임자는 시험 정답으로 튜닝하지 않으며 예측 저장 후 결과를 대조한다. 전원은 결과·한계를 교차검토한다.
