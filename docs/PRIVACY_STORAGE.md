# 저장·공유·삭제

원본 이미지·센서 로그·최종시험 정답은 data/raw 또는 data/private, 서비스 DB·업로드는 storage, 모델·APK는 artifacts에 둔다. 모두 Git 제외다. 공개 가능한 익명 manifest도 별도 검토 후 추적 경로로 내보낸다.

실제 사진에는 인물·위치·EXIF가 섞일 수 있다. 앱/서버의 보존 정책과 정제된 학습용 사본을 구분한다. 학습 사용 허용 여부·이용조건을 기록하고 무단으로 외부 AI 서비스에 전송하지 않는다. 원본에 포함된 개인정보를 합성 예제에 복사하지 않는다.

서버 계정마다 inspection 소유자를 확인한다. 개인키와 서명키는 Git·로그·프롬프트에 넣지 않는다. 개발 설정은 .env.example로 필드만 공유한다. 앱 내 상수는 비밀 저장소가 아니다.

최종시험 라벨은 권한을 제한한다. Git의 feature branch는 비밀 경계가 아니므로 공개 branch에 시험 정답을 넣지 않는다. 데이터 파트가 평가를 운영하고 예측을 고정한 다음 정답과 대조한다.

보존 기간·삭제 요청·학습 데이터에 반영하는 범위·백업 주기·복구 목표는 실제 운영 환경을 정할 때 확정한다. 실험/서비스 데이터 삭제 시 backup과 파생물 처리까지 기록한다. 데이터 복구 연습 전 운영 준비 완료라고 하지 않는다.
