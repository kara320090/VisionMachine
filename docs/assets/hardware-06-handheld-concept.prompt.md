# 휴대형 통합안 이미지 생성 프롬프트

초기 분산형 그림을 실제 현장 사용이 가능한 휴대형 장치로 바꾼다. Android 휴대폰은 후면 카메라를 가리지 않는 가장자리 클램프에 고정한다. 손잡이형 보호 본체 안에는 UNO R4 Minima 한 대, 적층된 DFR0265 한 대, DFR0759 한 대만 넣는다. 손잡이와 손목끈을 둔다. SEN0364와 SEN0206은 앞쪽의 하나의 측정 헤드에 나란히 고정하고 짧은 차광·거리 유지 구조를 둔다. SEN0334는 외기와 통하는 옆 통풍구 안에 둔다. SEN0308은 한 개만 사용하고, 측정 중에는 화분에 삽입하며 본체 옆 홀더는 비어 있는 모습으로 표현한다. 휴대폰과 본체 사이에는 짧은 USB-C 케이블 하나만 보인다. 다른 케이블은 본체 안이나 보호 슬리브로 정리한다.

제외: 센서 중복, 매달린 센서 보드, 긴 느슨한 케이블, 납땜, 브레드보드, 두 번째 제어보드, Wi-Fi 모듈, 외부 광원, 전자저울, 서버 장비, 추가 센서, 워터마크.
