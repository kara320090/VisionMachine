# 하드웨어 실물 배치 개념도 생성 프롬프트

용도: 핀 배선도가 아니라 물리적 배치를 이해하기 위한 보조 그림.

Android 휴대폰 한 대를 USB-C 데이터 케이블로 소형 보호함에 연결한다. 보호함 안에는 Arduino UNO R4 Minima 한 대, 그 위에 적층한 DFR0265 확장판 한 대, DFR0759 I2C 허브 한 대만 둔다. 보호함 밖에는 화분 흙에 꽂는 방수 토양수분 프로브, 외기에 노출하는 온습도 센서, 같은 잎을 향하는 가시광 분광 센서와 비접촉 적외선 표면온도 센서를 각각 한 개씩 둔다. I2C 센서 세 개는 허브에서 분기하고 토양 프로브는 아날로그 입력으로 연결한다. 휴대폰이 유일한 네트워크 게이트웨이다. 흰색 배경의 깔끔한 아이소메트릭 기술 일러스트로 표현한다.

제외: 납땜, 브레드보드, 두 번째 제어보드, Wi-Fi 모듈, 외부 광원, 전자저울, 서버 장비, 추가 센서, 세부 핀 텍스트, 워터마크.
