# 작물별 데이터 불균형 보정이 EfficientNet-B0 기반 8종 작물 정상·이상 분류에 미치는 영향

이 문서는 고정 프로토콜과 데이터 검토 기록으로 작성한 서론·방법 초안이다. 본실험 결과와 결론은 포함하지 않는다.

## 서론

여러 작물을 한 모델로 판별할 때 작물별 이미지 수와 정상·이상 비율이 함께 다를 수 있다. 전체 이미지에 대한 성능만 평가하면 자료가 많은 작물의 영향이 커지므로, 각 작물을 같은 비중으로 평가하는 통제 비교가 필요하다. 본 연구는 정상·이상 빈도만 보정하는 방법에 작물 정보를 추가하는 것이 작물별 이진 판별에 어떤 변화를 주는지 조사한다. 보정이 항상 개선된다는 가정은 두지 않는다.

구조는 ImageNet 사전학습 EfficientNet-B0로 고정한다. 기여는 새로운 알고리즘 제안이 아니라 동일한 데이터·초기화·증강·학습 예산에서 손실 가중 단위를 비교한 실증 결과에 둔다. 선행 연구의 확인 범위와 본 연구의 별도 설계는 reference_evidence.txt에 기록한다.

## 데이터와 주석

대상은 basil, bok_choy, cucumber, kale, lettuce, pepper, rosemary, tomato이며 normal=0, abnormal=1이다. 기존 processed 항목과 후속 사용자 지시에 따라 출처·이미지 검토를 거쳐 명시적으로 승인한 기존 raw 케일만 사용한다. 기존 이미지·메타데이터·링크는 수정하지 않고 포함·제외·교정은 실험 manifest에 기록한다.

processed 전수 점검은 파일 항목 60,593개, 고유 SHA-256 58,788개, 디코딩 오류 0개를 기록했다. 파일 항목 수, 고유 파일 수, 확인 가능한 사진 원본 관계와 촬영 그룹 수는 서로 다른 양이다. 파일명·지각 해시 유사도는 후보 생성에 사용하며 동일 사진이나 생물학적 독립성의 증거로 취급하지 않는다.

원출처 대조로 호박 사진과 대응한 케일 v5 129개 항목은 케일 학습에서 제외했다. 새 케일 정상 외관·잎 조직 소실 주석과 일부 청경채·로즈마리 정상 주석은 단일 AI의 시각 판정이다. 전문가 병리 검증·병원균 검사·독립 주석자 일치도는 확보하지 않았다. 기존 출처 주석과 새 시각 주석의 생성 방식 및 정상·이상 정의의 차이를 보존한다.

## 그룹 분할과 평가 대표

확인된 동일 사진 파생 관계와 누출 위험 촬영 그룹을 구분하여 관리하고, 같은 leakage_group_id는 하나의 분할에 배정했다. 분할 시드 20261016과 목표 비율 60/20/20으로 고정했다. 각 작물×상태의 검증·테스트에는 검토한 누출 방지 그룹이 최소 10개 존재하는지 검사했다. 이 운영 기준이 통계적 정밀도나 독립 개체 수를 보장하지는 않는다.

학습에는 정리된 공통 목록을 사용한다. 검증·테스트 주지표는 (촬영 그룹, 작물, 상태)별 사전 선정 대표 이미지로 계산한다. 아래 이미지 수는 manifest 항목 수이며 평가 대표 수와 구분한다.

## 모델과 손실

모델은 이미지 한 장만 받아 두 로짓을 출력한다. crop 정보는 손실 가중치와 평가에만 사용한다. N은 학습 이미지 수 34,622, n_y는 학습 상태별 수, n_c,y는 학습 작물×상태별 수다. A는 가중치 1, B는 N/(2 n_y), C는 N/(16 n_c,y)를 사용한다. 이미지별 Cross-Entropy에 가중치를 곱한 뒤 실제 배치 이미지 수로 평균한다. 배치 가중치 합으로 나누지 않는다. 균형 샘플러·가중치 상한은 기본 비교에 적용하지 않는다.

학습 목록에 16그룹이 모두 존재한다. B와 C의 평균 가중치는 1, 각 상태의 가중치 합은 17,311이다. C의 각 작물×상태 합은 2,163.875다. 검증·테스트 수는 가중치 계산에 사용하지 않았다.

## 공통 학습 설정

전용 환경과 공통 설정은 configs/common.json 및 reproducibility/environment.json, requirements.lock.txt에 보관한다. EfficientNet-B0 IMAGENET1K_V1의 마지막 Linear를 2출력으로 교체한다. 배치 크기는 64, AdamW의 weight decay는 1e-4이다. 분류기만 2 epoch 학습한 뒤 전체를 28 epoch 미세조정한다. 초기 분류기 학습률은 1e-3이며 전체 미세조정은 backbone 1e-4, classifier 1e-3에서 시작해 cosine으로 시작의 1%까지 감소시킨다. 조기 종료 없이 총 30 epoch를 수행한다.

원본을 변경하지 않고 EXIF 방향 보정·RGB 변환·짧은 변 320의 PNG 캐시를 실험 폴더에 생성했다. 캐시에서 학습용 224×224 RandomResizedCrop(scale 0.9–1.0, ratio 0.95–1.05), 수평 반전 0.5 및 약한 색 변화를 적용한다. 검증·테스트는 짧은 변 256 bicubic resize와 중앙 224 crop을 사용한다. ImageNet mean/std로 정규화한다. 캐시의 선행 축소도 실제 입력 파이프라인의 일부로 재현해야 한다.

AMP·GradScaler와 gradient norm 상한 1.0을 공통 적용한다. 시드 17, 42, 2026 각각에서 A/B/C를 순차 학습한다. 같은 시드의 모델 초기화 해시·학습 목록 순서·epoch별 셔플 및 이미지별 증강 난수를 대응시키고, 실제 optimizer 업데이트·AMP skip·실행 시간·재시작을 기록한다. 플랫폼이 달라져도 완전 동일 결과가 나온다고 보장하지 않는다.

## 모델 선택과 분석

검증에서 작물별 normal/abnormal F1의 평균을 먼저 구하고 이를 8종 동일 비중으로 평균한 값이 가장 높은 epoch를 선택한다. 동률이면 이른 epoch를 선택한다. 테스트에서 p(abnormal)≥0.5를 공통 적용하며 테스트로 설정·임계값·체크포인트를 선택하지 않는다.

전체 pooled binary macro-F1과 정확도는 보조 지표다. 작물별 이상 검출률, 정상 오판율, 혼동행렬과 같은 시드의 B−A, C−B, C−A 차이를 보고한다. 조건별 3시드 평균과 표본 SD를 제시하되 유의성의 증거로 과장하지 않는다. 오분류 예시는 seed17의 조건×작물×오류 종류별 image_id 정렬 앞 3개라는 고정 규칙으로 선정한다.
