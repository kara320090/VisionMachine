# 논문·모델 자료 상태

논문·검토 핵심 자료를 선정했고 최종 모델 3/9개가 이 커밋에 포함된다. 모델의 조건·시드·선택 epoch·SHA-256은 provenance/MODELS.csv에 기록했다.

대형 전수 데이터 목록과 중간 모델은 로컬 원본에 보존했다. 검토 화면·이미지·시각 주석·출처와 중복 검토 근거를 포함했다. 새로운 학습·추론·앱 배포는 실행하지 않았다.

검증 명령은 python tools/verify_paper_bundle.py 이다. 전체 모델 포함 여부까지 확인하려면 --require-all-models를 지정한다. 전체 분할 CSV가 공개되지 않았으므로 공개본 검사는 분할 누수를 새로 전수 검증하지 않는다. 로컬 원본으로 수행한 분할 검증 기록은 provenance/SPLIT_SUMMARY.json과 선정 기록에 남겼다.
