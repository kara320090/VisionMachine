# 손실 가중 단위 비교: 결과 해석과 재현

2026-10-23 논문 설명 보완 자료이다. 고정된 9개 실행의 저장 예측을 다시 계산했으며 새 학습이나 테스트 자료 추가는 없다. 연구 기준 자료는 커밋 `f6345ccfb817c62bf6b2f11eede369e05212f228`에 보존되어 있다.

## 용어와 비교 대상

- **손실 함수**는 세 조건 모두 교차 엔트로피이다.
- **손실 가중 단위**는 역빈도를 계산할 자료 묶음이다. A는 무가중, B는 정상·이상 상태, C는 작물×상태 16개 조합을 사용한다.
- 샘플 가중 교차 엔트로피의 합을 배치 영상 수로 나눈다. 가중치 합으로 나누는 방식과 구분한다.
- 학습 전체 수를 N, 상태별 수를 n(y), 작물×상태별 수를 n(c,y)라 하면 A=1, B=N/[2n(y)], C=N/[16n(c,y)]이다. 작물 종류는 가중치 산정에 사용하며 모델 입력은 영상이다.

학습 34,622장 중 정상은 25,019장, 이상은 9,603장이다. B의 영상별 가중치는 정상 0.691914, 이상 1.802666이다. B는 두 상태의 **가중치 합**을 각각 N/2로 맞추지만 상태 안의 작물 비율은 유지한다. C는 16개 조합의 가중치 합을 각각 N/16으로 맞춘다. 이는 실제 손실이나 기울기까지 같게 한다는 뜻은 아니다. 실제 손실은 예측 오차에도 의존한다.

## 관측 결과

값은 세 시드(17, 42, 2026)의 대응 차이 평균 ± 표본표준편차이며 단위는 %p이다.

| 비교 | 작물 평균 macro-F1 차이 | 전체 pooled macro-F1 차이 |
|---|---:|---:|
| B-A | -0.29 ± 0.08 | -0.37 ± 0.25 |
| C-B | +0.88 ± 0.36 | +0.43 ± 0.38 |
| C-A | +0.59 ± 0.37 | +0.05 ± 0.28 |

B는 A보다 주지표가 세 시드에서 모두 낮았다. 작물별 평균에서는 바질 -1.99%p, 상추 -0.49%p가 나타났다. 바질의 이상 재현율은 A 84.30%에서 B 78.26%로 낮아졌고, 정상 오탐률도 11.88%에서 8.58%로 낮아졌다. 즉, 상태 역빈도 가중의 도입 자체가 작물 평균 F1 개선을 보장하지 않았으며 재현율과 오탐률이 함께 달라졌다. 이 관측만으로 특정 학습 기전을 확정하지 않는다.

C의 주지표 91.32%는 A 90.73%, B 90.44%보다 높다. C-B 작물별 평균 차이는 6종 양수, 고추 동률, 오이 음수이다. 로즈마리 +4.35 ± 4.34%p, 케일 +1.16 ± 3.89%p이며 오이는 -0.38 ± 1.32%p이다. C-A에서는 로즈마리 +4.28%p, 케일 +1.22%p, 청경채 +0.32%p이나 바질·오이·상추·토마토 평균 차이는 음수이다(토마토 약 -0.00043%p). 따라서 모든 작물에서 C가 우수하다는 주장이 아니다.

C-A의 pooled 차이는 +0.05%p인 반면 작물 평균 차이는 +0.59%p이다. C의 작물×상태 단위 가중은 작물마다 같은 비중을 부여한 평가 목표와 대응한다. 관측된 개선은 이 평가 목표와 자료 조건 안에서 해석하며, 통계적 유의성이나 외부 환경 성능의 증거로 확장하지 않는다. 시드별 표준편차는 신뢰구간이 아니다.

## 공개 자료로 재계산

저장소를 내려받아 `ComputerVision-ai` 디렉터리에서 실행한다. 두 명령은 Python 표준 라이브러리만 사용하며 모델을 불러오거나 GPU 학습을 실행하지 않는다. 저장소 루트의 앱 실행용 의존성을 설치할 필요도 없다.

```text
python -B tools/verify_paper_bundle.py --require-all-models
python -B followups/20261023_weighting_unit/reproduce_discussion.py
```

첫 명령은 공개 파일 SHA-256, 9개 선택 모델, 270 epoch 이력, 고정 코드·설정, 가중치 집계, 16,956개 테스트 예측과 성능표를 확인한다. 두 번째 명령은 9개 예측 파일의 평가 ID·라벨·누수 방지군이 같은지 확인하고, 임계값 0.5에서 조건별/작물별 지표와 B-A·C-B·C-A 대응 차이, 가중치 합을 계산한다. 출력은 [results.json](results.json)과 비교할 수 있다. 기존 예측·라벨·모델 파일을 변경하지 않는다.

관련 파일은 [고정 설정](../../configs/common.json), [고정 코드·설정·분할 해시](../../configs/protocol_lock.json), [모델 목록](../../provenance/MODELS.csv), [공개 파일 해시](../../provenance/PUBLIC_FILES.csv), [평가 예측](../../evaluation), [학습 환경](../../reproducibility/environment.json)이다. 학습 환경은 Python 3.10.12, PyTorch 2.9.0+cu128, torchvision 0.24.0+cu128, CUDA 12.8, RTX 4090이다.

## 재학습 범위

저장 예측 기반 지표 재계산과 동일 자료를 이용한 재학습은 서로 다른 절차이다. 공개본은 코드·설정·시드·선택 모델·예측·집계·분할 해시를 제공한다. 동일 분할 재학습은 별도로 보관한 전체 `fixed_split.csv`와 원본 이미지·캐시를 사용한다. 공개 집계만으로 이미지별 전체 분할을 복원할 수는 없다. [원본 보존 범위](../../LOCAL_ONLY.md)와 [학습 환경·재현 안내](../../reproducibility/REPRODUCE_LINUX.md)를 함께 따른다.
